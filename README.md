# Pharmacy Management System

A command-line pharmacy management system built with Python.

## Features
-  Drug Stock Management
-  Patient Records
-  Sales Tracker
-  Expiry Checker
-  Daily Report Generator

## Tech Stack
- Python 3
- File I/O
- DateTime module
- Data Structures (Dictionary, Lists, Tuples)

## How to Run
```bash
python pharmacy_system.py
```

## Project Structure
pharmacy_system.py     ← main program
pharmacy_stock.txt     ← stock data
patients.txt           ← patient records
prescriptions.txt      ← sales history
expiry_data.txt        ← expiry dates
daily_report.txt       ← generated reports
